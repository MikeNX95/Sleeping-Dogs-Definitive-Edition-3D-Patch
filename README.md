# Sleeping-Dogs-3D-MOD

Sleeping-Dogs-3D-MOD Patch


The mod takes the game's internal 3D SBS output and adds support for pretty much every 3D display format—Top and Bottom (tab and tab_reversed), Side-by-Side (sbs and sbs_reversed), interlaced (interlaced and interlaced_reversed), checkerboard (checkerboard and checkerboard_reversed), plus LeiaSR displays.

DLSS Supported


### 📦 Installation

1. Download and extract the latest release archive (containing `dinput8.dll` `config.ini` and `leiasr_shim.dll`).
2. Place `dinput8.dll` and  `config.ini` directly into your main game directory right next to `game.exe`.
4. If you are using a LeiaSR display, place `leiasr_shim.dll` into the same directory right next to `game.exe`, then select output mode **7**.
