# Sleeping Dogs: Definitive Edition — 3D Mod

A stereoscopic 3D patch for **Sleeping Dogs: Definitive Edition** that intercepts the game's internal 3D Side-by-Side (SBS) output and adds native support for a wide range of 3D display formats, alongside full DLSS compatibility.

### ✨ Features
* **Universal 3D Display Support:**
  * **Top & Bottom:** `tab`, `tab_reversed`
  * **Side-by-Side:** `sbs`, `sbs_reversed`
  * **Interlaced:** `interlaced`, `interlaced_reversed`
  * **Checkerboard:** `checkerboard`, `checkerboard_reversed`
  * **LeiaSR:** Native hardware support
* **DLSS Supported:** Works seamlessly with DLSS enabled.
* **In-Game Overlay:** Adjust 3D settings on the fly using the built-in menu.

### 📦 Installation

1. Download and extract the latest release archive. 
2. Copy all the content directly into your main game installation directory (next to `game.exe`).
3. *(Optional — LeiaSR Displays Only)* Copy `leiasr_shim.dll` into the same directory next to `game.exe`, then select output mode **7**.
4. Launch the game and press **`Insert`** on your keyboard to open the overlay menu.
